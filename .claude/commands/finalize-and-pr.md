# /finalize-and-pr

프로젝트의 모든 변경사항을 커밋하고 develop 브랜치 대상으로 상세한 PR을 자동 생성합니다.

## 사용법
```
/finalize-and-pr [간단한 작업 설명]
```

## 예시
```
/finalize-and-pr FAQ 기능 조건부 비활성화 구현
/finalize-and-pr 동적 userId 설정 및 APP001 대응
/finalize-and-pr 채팅 UI 개선 및 버그 수정
```

## 작업 내용

이 명령을 실행하면 다음 작업을 자동으로 수행합니다:

### 1. 프로젝트 상태 확인
- 루트 디렉토리로 이동하여 모든 변경사항 확인
- git status로 수정/추가/삭제된 파일 검증
- 커밋되지 않은 변경사항 감지

### 2. 변경사항 스테이징 및 커밋
- `git add .`로 모든 변경사항 스테이징
- 백업 파일(.json, .bak 등) 제외 처리
- 구조화된 커밋 메시지 자동 생성:
  ```
  feat/fix: [작업 설명]
  
  ## 🎯 주요 변경사항
  [변경된 파일별 상세 설명]
  
  ## 🔧 구현 방법
  [기술적 구현 내용]
  
  ## 🚀 개선 효과
  [성능/안정성 개선 사항]
  
  🤖 Generated with [Claude Code](https://claude.ai/code)
  
  Co-Authored-By: Claude <noreply@anthropic.com>
  ```

### 3. 원격 저장소 푸시
- 현재 브랜치를 origin으로 푸시
- 푸시 상태 확인 및 결과 리포트

### 4. Pull Request 생성
- **타겟 브랜치**: develop (기본값)
- **저장소**: meeta-inc/ai-navi-outbound-cs-314community-frontend
- 상세한 PR 설명 자동 생성

## PR 템플릿 구조

생성되는 PR은 다음 구조를 따릅니다:

```markdown
## 🎯 개요
[작업의 배경과 목적]

## 🚀 주요 변경사항
### 1. [변경 영역 1]
- **문제**: [해결한 문제점]
- **해결**: [구현한 해결책]
- **효과**: [개선 효과]

### 2. [변경 영역 2]
[동일한 구조로 반복]

## 🔧 구현 방법
### [기술적 구현 내용]
[코드 예시와 설명]

## 📋 변경된 컴포넌트

[수정된 React 컴포넌트 목록]

### 스타일 및 설정
[CSS, 설정 파일 변경사항]

## 🧪 테스트 결과
### 기능 테스트
[수동 테스트 결과]

### 브라우저 호환성
[테스트한 브라우저 목록]

## 📱 반응형 대응
[모바일/태블릿 대응 상황]

## ⚠️ 향후 주의사항
### 1. [주의사항 1]
[상세 설명]

[상세 설명]

## 📁 변경된 파일
[주요 변경 파일 목록]

🤖 Generated with [Claude Code](https://claude.ai/code)

Closes #[이슈번호]
```

## 자동 작업 세부사항

### 커밋 메시지 생성 규칙
- **feat**: 새로운 기능 추가
- **fix**: 버그 수정
- **refactor**: 코드 리팩토링
- **style**: UI/UX 개선
- **chore**: 빌드, 설정 변경

### PR 제목 생성 규칙
```
[type]: [간단한 설명] + 핵심 키워드
```

### 변경사항 분석
- React 컴포넌트별 변경 내용 분석
- TypeScript 타입 정의 변경사항
- Tailwind CSS 스타일 변경사항
- 컨텍스트 및 훅 변경사항

### 프론트엔드 특화 분석
- 컴포넌트 아키텍처 패턴
- 상태 관리 방식
- 사용자 경험(UX) 개선 포인트
- 접근성(a11y) 고려사항

## 실행 조건

- Git 저장소여야 함
- 변경사항이 존재해야 함
- GitHub 토큰이 설정되어 있어야 함
- 현재 브랜치가 feature/ 또는 hotfix/ 패턴이어야 함

## 주의사항

### 사전 확인 사항
- npm run lint 실행 후 주요 에러 수정
- 컴포넌트 동작 테스트 완료
- 브라우저 개발자 도구에서 에러 없음 확인
- 반응형 레이아웃 정상 동작 확인

### 자동 제외 파일
- `*.json` (백업 파일)
- `*.bak`
- `*.tmp`
- `node_modules/`
- `dist/`
- `.env*` (환경 변수 파일)
- `coverage/`

### 에러 처리
- git 충돌 발생 시 수동 해결 안내
- 네트워크 오류 시 재시도 로직
- PR 생성 실패 시 수동 생성 가이드

## 사용 전 체크리스트

- [ ] 주요 기능이 브라우저에서 정상 동작하는지 확인
- [ ] TypeScript 컴파일 에러 없음 확인
- [ ] 린트 에러 중 새로 추가된 것이 없는지 확인
- [ ] 접근성 기본 요소 확인 (버튼, 링크 등)
- [ ] 모바일 화면에서 정상 동작 확인

이 명령어는 프론트엔드 개발 작업의 마무리 단계를 완전 자동화하여 일관성 있고 상세한 PR을 생성합니다.
