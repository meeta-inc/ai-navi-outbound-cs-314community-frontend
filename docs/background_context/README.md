# Background Context

이 디렉토리는 AI Navi 아웃바운드 CS 314 커뮤니티 프론트엔드 프로젝트의 배경 맥락과 도메인 지식을 문서화합니다.

## 목적

개발팀이 프로젝트의 비즈니스 맥락과 도메인 지식을 이해하고, 새로운 팀 구성원이 빠르게 프로젝트에 적응할 수 있도록 돕습니다.

## 문서 구조

### 1. 비즈니스 맥락
- **business-overview.md**: 비즈니스 개요 및 목표
- **user-personas.md**: 사용자 페르소나 및 사용 시나리오
- **business-requirements.md**: 비즈니스 요구사항 및 제약사항

### 2. 도메인 지식
- **domain-glossary.md**: 도메인 용어 사전
- **customer-service-workflow.md**: 고객 서비스 워크플로우
- **llm-integration-context.md**: LLM 통합 배경 및 요구사항

### 3. 기술적 맥락
- **technical-constraints.md**: 기술적 제약사항 및 요구사항
- **integration-dependencies.md**: 외부 시스템 연동 의존성
- **performance-requirements.md**: 성능 요구사항 및 목표

### 4. 운영 맥락
- **deployment-environment.md**: 배포 환경 및 인프라
- **monitoring-logging.md**: 모니터링 및 로깅 전략
- **security-context.md**: 보안 요구사항 및 가이드라인

## 문서 작성 가이드라인

### 1. 작성 원칙
- **명확성**: 기술적 배경이 없는 사람도 이해할 수 있도록 작성
- **구체성**: 추상적인 설명보다는 구체적인 예시 포함
- **최신성**: 변경사항이 있을 때마다 문서 업데이트
- **연관성**: 관련 문서 간 상호 참조 링크 제공

### 2. 업데이트 주기
- 비즈니스 요구사항 변경 시
- 새로운 기술 도입 시
- 외부 시스템 연동 변경 시
- 분기별 정기 검토

### 3. 문서 템플릿

```markdown
# {문서 제목}

## 개요
{문서의 목적과 범위}

## 배경
{왜 이 정보가 필요한지 설명}

## 상세 내용
{구체적인 내용}

## 영향도
{이 맥락이 개발에 미치는 영향}

## 관련 문서
- {관련 문서 링크}

## 최종 업데이트
{날짜 및 변경 사유}
```
